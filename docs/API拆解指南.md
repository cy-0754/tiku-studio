# 网页上传 PDF 自动拆解（LLM API，实验性）

不想装 Agent 的话，可以在网页直接上传 PDF，由视觉大模型拆解。
需要你自己的 API key（按 token 计费，一册教辅通常几毛到几块钱）。

## 配置

「设置」页 → 选供应商 → 填 API Key → 保存。

| 供应商 | 推荐模型 | 获取 Key |
|---|---|---|
| 智谱 GLM | glm-4v-plus（默认，视觉） | open.bigmodel.cn |
| OpenAI 兼容 | gpt-4o / 其他 | platform.openai.com 或任意兼容网关（选 custom 填 base_url） |

DeepSeek 当前无视觉模型，上传 PDF 拆题请用 GLM / OpenAI 兼容网关。

## 使用

「AI 拆解」页 → 方式二 → 选 PDF → 填元信息（科目/年级/学期/版本/资料类型）→ 开始拆解。

流程：后端把 PDF 每页转图（默认最多 30 页，可在设置改）→ 发给视觉模型 → 返回 bundle →
**先预览前 10 题** → 你确认后点「导入题库」→ 进待审核队列。

## 与 Agent 模式怎么选

| | Agent 模式 | LLM API 模式 |
|---|---|---|
| 费用 | 免费（用 Agent 订阅） | 按 token 计费 |
| 质量 | 更高（可多轮自查、翻书核对、抓网页资料） | 一次成型，复杂版面可能漏题 |
| 门槛 | 需要装过 ZCode/Claude Code | 浏览器里点几下就行 |
| 适用 | 整册书、重要资料 | 快速试一把、单份试卷 |

两者产物是同一套 schema，可以混用：重要资料走 Agent，零散试卷走网页上传。

## 注意

- 扫描质量差的 PDF（斜、糊、手写）拆解效果差，先校正再传。
- 拆解结果始终先预览、先进待审核——模型会出错，你的确认是最后一道关。
- API key 保存在本地 `data/tiku.db`，不会离开你的机器（调用时直连供应商）。

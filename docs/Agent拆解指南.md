# 把新课本教辅交给本地 Agent 拆解（免费，推荐）

适合：整册课本建纲、整本教辅题目级拆解、需要联网抓取资料的场合。
不花 API 钱——拆解的是你的本地 Agent（ZCode / Claude Code 等）。

## 一次性的准备

1. 在项目目录打开你的 Agent（如 ZCode CLI 就 `cd tiku-studio` 后启动）。
2. Agent 会读仓库根目录的 `AGENTS.md` → 指向 `agent/AGENTS.md` 拆解手册。手册里有：
   两种任务（目录级 / 题目级）的标准流程、schema 约定、校验命令、常见坑。

## 场景一：新课本建纲（每个年级每册做一次）

复制 `agent/prompts/目录级拆解-课本建纲.md` 的提示词，改好路径发给 Agent：

> 请阅读本仓库的 agent/AGENTS.md 拆解手册，然后执行目录级拆解任务：
> 源文件：E:\课本\二年级数学下册.pdf；元信息：数学，二年级，下册，北师大版，2024 …

Agent 会：转页图 → 识别目录与知识点 → 生成 bundle 到 `data/inbox/` → 自动校验入库。
**纲的质量决定后面所有卷子的超纲判定**，导入后去「资料库」点开目录检查一遍知识点。

## 场景二：教辅/试卷拆题（可反复做）

复制 `agent/prompts/题目级拆解-试卷教辅入库.md`，改好路径发给 Agent。要点：

- 挂靠课本纲必须已存在（不存在先做场景一）；
- 知识点命名由 Agent 从纲里复制，保证对纲校验能匹配上；
- 教辅里有意超前的提优题会被标为「提优拓展」并附理由。

## 拆解产物的三种投递方式

| 方式 | 操作 |
|---|---|
| Agent 自动入库 | Agent 直接跑 `python scripts/import_bundle.py data/inbox/xxx.json` |
| 网页导入 | Agent 只投递 JSON 到 `data/inbox/` → 网页「资料库」页点「校验并导入」 |
| 手动上传 | 网页「AI 拆解」页拖入 bundle JSON 文件 |

## 审核与组卷

导入的题全部处于**待审核**状态（不会立刻进组卷池）。去「待审核」页逐条确认；
「疑似超纲」的题会展示判定理由（缺哪个知识点/可能是版本不符），你说了算。

## 质量检查清单（家长版）

- [ ] 课本纲：每个单元知识点数量合理（数学 4~10 条/单元），没有三年级内容混进一年级
- [ ] 抽 3 道题对答案（Agent 会汇报它自查的结果，你抽查即可）
- [ ] 看图题的题干是否完整（缺图的题在题库详情里能看到"无图"标记，可编辑补文字描述）
- [ ] 待审核队列清零后再组卷

# 提示词：题目级拆解（试卷/教辅入库）

把下面这段话发给你的本地 Agent（ZCode / Claude Code），替换路径与元信息即可：

---

请阅读本仓库的 `agent/AGENTS.md` 拆解手册，然后执行题目级拆解任务：

- 源文件：`<你的试卷/教辅 PDF 路径>`
- 元信息：role=<workbook/paper_set/self_made>，科目 <…>，年级 <N>，学期 <…>，
  出版社版本 <…>，版别年份 <…>，标题 <如：53天天练数学一年级上>
- 挂靠课本纲：`<对应教材 title，如：人教版数学一年级上册（2024）>`
  （先查数据库确认它存在；不存在就先按《目录级拆解》提示词建纲）

要求：
1. 每道题独立拆出：stem / options / answer / analysis / q_type / difficulty / knowledge_points。
2. 知识点字符串从课本纲的 units.knowledge_points 里复制，不要手打。
3. 教辅中明确超前的提优题：`scope_status: "extension"` + `scope_reason`（说明对应课本哪页/哪个拓展）。
4. 无法用符号表达的看图题：裁剪题图为 PNG 放 `data/inbox/images/<册名>/`，bundle 里写相对路径。
5. 产物投递到 `data/inbox/questions-<册名>.json`，然后：
   `python scripts/import_bundle.py data/inbox/questions-<册名>.json`
6. 汇报：拆出多少题、各题型数量、多少题被判为提优、需要人工复核的题号。

# 提示词：目录级拆解（课本建纲）

把下面这段话发给你的本地 Agent（ZCode / Claude Code），替换书名即可：

---

请阅读本仓库的 `agent/AGENTS.md` 拆解手册，然后执行目录级拆解任务：

- 源文件：`<你的课本 PDF 路径，例如 E:\课本\二年级数学下册.pdf>`
- 元信息：科目 <数学/语文/英语>，年级 <N>，学期 <上册/下册>，出版社版本 <人教版/统编版/北师大版…>，版别年份 <2024>
- 产物：catalog-bundle，投递到 `data/inbox/catalog-<科目><年级><学期>.json`

要求：
1. 这本书是 role=textbook 的『纲』，每个单元的 knowledge_points 是后续对纲校验的标尺，
   请从目录页和每个单元首页提取本单元真正覆盖的知识点（中文短语，稳定命名）。
2. 有课时目录就列出课时（seq + name + 印刷页码范围）。
3. 完成后运行 `python scripts/import_bundle.py data/inbox/catalog-<...>.json` 完成校验入库，
   然后运行 `.venv/Scripts/python -m pytest apps/api/tests -q` 确认无误。
4. 汇报：共识别几个单元、多少课时、多少知识点，以及需要我人工复核的点。
